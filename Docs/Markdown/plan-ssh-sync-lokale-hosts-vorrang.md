# Plan: lokale Hosts haben Vorrang vor dem managed Block

- Annahme: OpenSSH nimmt HostName/User/Port beim ersten Treffer und sammelt `IdentityFile` ueber alle passenden Bloecke. Ein managed Host am Dateiende aendert deshalb trotz Vorrang der lokalen Werte die Schluesselliste. `Host *` ohne `IdentityFile` gilt nicht als lokale Definition einzelner Hosts; mit `IdentityFile` entsteht dieselbe Sammel-Wirkung fuer jeden Alias. Kein Release/Tag in dieser Arbeit.
- Zwei Wege:
  1. **Auftragsweg (gewaehlt):** Vor dem Rendern des managed Blocks die vorhandene Config ausserhalb der Marker parsen. Fuer jeden Server-Alias, den ein lokales `Host`-Muster trifft (Mehrfachmuster, Wildcards, Negation wie OpenSSH), keinen managed-Eintrag schreiben. `Host *` allein zaehlt nicht; definiert er `IdentityFile`, entfallen in managed Hosts die Zeilen `IdentityFile`/`IdentitiesOnly` (HostName/User/Port bleiben), damit neue Server-Hosts weiter erscheinen und keine zusaetzlichen Keys angehaengt werden. Trockenlauf und Apply listen ausgelassene Aliase: `lokal definiert, uebersprungen: …`.
  2. **Alternative (gelassen):** Nur `IdentityFile` in managed Hosts weglassen, Eintrag aber immer schreiben. Das wuerde User/Port/HostName aus dem Server weiter andeuten, obwohl lokal schon gesetzt; bei abweichenden Server-Werten aendert sich `ssh -G` nicht (erster Treffer), der Block wuerde aber doppelte Absicht zeigen und bei spaeterem Loeschen lokaler Zeilen still umschalten. Volistaendiges Weglassen ist klarer.
- Ablehnung: Ein Kollege koennte verlangen, bei `Host *` plus `IdentityFile` alle managed Hosts komplett auszulassen. Das wuerde Sync auf Geraeten mit globalem IdentityFile leeren. Stattdessen nur Identity-Zeilen unterdruecken.
- Nachweis: `go test ./internal/sshconfig/ -count=1` (Parser-Muster/Negation, Skip-Liste, unveraenderte `ssh -G`-IdentityFile-Liste); Wegwerf-Container `debian:bookworm-slim` + `openssh-client` mit vm88-aehnlicher Beispiel-Config.
- Grenze: kein Release, kein Tag, keine Daemon-/Installer-Aenderung, keine produktiven Hosts, Version bleibt bis Firstmate v0.1.9 schneidet.
